# MS-01: Build a permission-gated, bounded live-source fetch policy

## Goal / Context

The baseline reads local HTML only. Implement the safety and source-approval boundary before adding any live property site.

## Exact Files to Touch

- `services/market-scraper/src/fetch-policy.ts` (add)
- `services/market-scraper/sources.example.json`
- `tests/unit/fetch-policy.test.ts` (add)
- `docs/scraper-sources.md` (add)

## Concrete Acceptance Criteria

- [ ] Default every source to disabled; document an approved source/domain and permission basis before enabling it.
- [ ] Require HTTPS, allowlist hosts, reject private/loopback/link-local destinations and revalidate every redirect/DNS resolution.
- [ ] Honor a documented robots policy, explicit request interval, timeout, response-size limit and bounded retry budget.
- [ ] Test redirects to disallowed/private hosts, blocked robots rules, timeouts and maximum response size without network access.
- [ ] Never bypass logins, paywalls, captchas or site access restrictions.

## Verification Command

Run from the repository root after `npm ci --ignore-scripts`:

```powershell

npm run test:scraper
```
