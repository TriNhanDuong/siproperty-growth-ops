# LR-04: Deliver leads to Google Sheets with retry-safe row identity

## Goal / Context

Add the first useful sink behind an explicit enable flag. A local fake Sheets transport must be sufficient to prove behavior; no real sheet is provided.

## Exact Files to Touch

- `services/lead-router/src/adapters/sheets.ts` (add)
- `services/lead-router/src/server.ts`
- `tests/integration/sheets.test.ts` (add)
- `.env.example`
- `docs/data-handling.md` (add)

## Concrete Acceptance Criteria

- [ ] Authenticate through deployment-injected credentials and a configured sheet ID, with least-privilege sharing documented.
- [ ] Use a stable event ID column and reconciliation so timeout-after-write does not append duplicate leads.
- [ ] Retry 429/5xx with bounded delay; permanent failures go to a dead letter without raw payload logging.
- [ ] Apply formula-injection escaping to strings beginning with =, +, - or @ before writing spreadsheet cells.
- [ ] Test duplicate delivery, timeout-after-write, permission failure and dangerous cell input using fake transport.
