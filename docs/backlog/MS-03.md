# MS-03: Persist observations and export comparable pricing summaries

## Goal / Context

Turn synthetic observations into typed storage and reproducible descriptive summaries. Do not present asking-price aggregates as appraisals or transaction prices.

## Exact Files to Touch

- `services/market-scraper/src/store.ts` (add)
- `services/market-scraper/src/valuation.ts` (add)

## Concrete Acceptance Criteria

- [ ] Validate observation IDs, UTC timestamps, project IDs, source attribution and VND unit.
- [ ] Upsert by source/listing/time identity; duplicate runs do not multiply observations.
- [ ] Compute medians only within the same project, currency and unit; flag sample size and stale records.
- [ ] Export CSV with safe string escaping and no customer records.
- [ ] Test mixed-unit rejection, stale data, duplicate runs and insufficient samples.
